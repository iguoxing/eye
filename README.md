# Global Demand Eye · 全球需求洞察方法论

> 什么产品，在哪个国家，现在更容易卖得好？

一套产品无关的外贸需求洞察方法论，核心为 **DPI 需求潜力指数**：

```
DPI = 需求规模(25%) + 增长动能(25%) − 竞争烈度(20%) − 进入门槛(15%) + 供应链匹配(15%)
```

## 内容

- 六层需求信号数据源（海关提单 / UN Comtrade / Google Trends / 电商 / 社媒 / 宏观准入）
- DPI 五维度评分模型与权重说明
- 交互式 DPI 在线计算器（产品、国家、维度分、权重均可调）
- 五步验证闭环（海关数据 → 决策人 → 触达 → 验厂 → 结果回写）
- 90 天 MVP 落地路线
